## Why Astro?

Astro is a modern static site generator that ships zero JavaScript by default. It's perfect for content-focused websites where performance matters.

## Key Features

- **Islands Architecture** — Only hydrate interactive components
- **Content Collections** — Type-safe markdown management
- **View Transitions** — Built-in SPA-like navigation
- **Framework Agnostic** — Use React, Vue, Svelte, or just HTML

## Getting Started

```bash
npm create astro@latest
```

Astro provides an excellent developer experience with its built-in dev server and straightforward project structure.
